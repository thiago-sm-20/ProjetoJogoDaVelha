# ProjetoJogoDaVelha
Um projeto escrito em C/C++ que simula um jogo da velha. 

# Tecnologias Usadas:
Esse projeto utiliza uma matriz em array para armazenar o tabuleiro de jogo e variáveis globais para o estado do jogo.
O projeto está dividido no padrão MVC (Model-View-Controller) para melhor distribuição do código. 
Ainda está em desenvolvimento. 

# Instruções para instalação. 
Para executar o projeto basta baixar os arquivos no repositório e abrir o "JVelha-Projeto.cpp" e compilar.
